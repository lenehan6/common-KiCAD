## How to change priorities / groups

- Quick: edit `libraries.priority` / `libraries.grp` in `catalog.sqlite` (and `symbols` for the same library: `UPDATE symbols SET priority=? WHERE library=?`). Lost on re-run.
- Durable: create `application_dbl/triage_overrides.json` and re-run with `--overrides`:

```json
{"4xxx": {"grp": "application", "priority": 6},
 "FPGA_Xilinx_Spartan6": {"grp": "application", "priority": 5, "note": "still in use"}}
```

```sh
python3 tools/scan_kicad_symbols.py --src kicad-symbols-10.0.8.tar.gz --ref 10.0.8 \
  --sym-lib-table <path/to/sym-lib-table> --out application_dbl/catalog.sqlite \
  --triage application_dbl/TRIAGE.md --overrides application_dbl/triage_overrides.json
```

Overrides apply per library (`grp` one of application/commodity/nonbom/legacy, `priority` int, optional `note`); USB symbols in Connector keep priority 0 and power-flagged symbols stay nonbom.
